# 📚 Research & Publications

My research focuses on the security and integrity of generative AI systems: verifying LLM data through blockchain-based supply-chain validation, and validating LLM computations with Zero-Knowledge Proofs. I'm now researching the reliability of autonomous AI agents.

- **ICAIR 2024** (Lisbon, Portugal): *LLM Supply Chain Provenance: A blockchain-based approach*
- **ICCWS 2024** (Johannesburg, South Africa): *Enhancing privacy and security in large-language models: a zero-knowledge proof approach* 
- **THREAT 2023** (Stellenbosch, South Africa): *Towards Authenticity of Large-Language Model Computations using Zero-Knowledge Proof Validations*
